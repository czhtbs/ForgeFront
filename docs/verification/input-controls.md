# 鼠标输入修复记录

日期：2026-11-10。

- 右键菜单：此前只在 Phaser 画布上拦截，侧栏和覆盖层仍触发浏览器菜单。现在在游戏根节点的捕获阶段统一取消 `contextmenu`，不拦截游戏所需的鼠标按下、移动和松开事件。
- 光标缩放：Phaser 4 的 `setZoom()` 不立即更新 `getWorldPoint()` 使用的矩阵，旧逻辑前后得到同一坐标，补偿为零。现在在缩放前、缩放后和补偿后刷新矩阵，并忽略垂直变化量为零的滚轮事件。
