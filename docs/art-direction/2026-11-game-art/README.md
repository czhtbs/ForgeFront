# 正式游戏美术与地图 · 2026-11-07

> 本文保留前轮素材记录。地块形状、配色、死亡与补给交互已被[后续反馈修正](../2026-11-soft-relief/README.md)更新；当前正式地图是随机分割，不是六边形。

本轮资源直接由正式游戏 `MapScene` 加载，独立 `art-preview` 保留为旧版对照。

## 地图与尺度

- 小／中／大地图为 40／60／80 个正六边形；半径恒定 60，单块面积约 9353。增加地块只扩大地图，不缩放地块或士兵。
- 人物主体 5.4，建筑宽 22–36；同样镜头倍率下，三种地图的单位尺度相同。武器射程与身长比例沿用原值。
- 单树 9–14、单山 16–23；同一种子生成相同的零散与聚集分布。完整贴图包围盒保持在所属地块内，避开建筑位置。
- 装饰仅影响画面与遮挡，不新增阻挡移动、掩体或射界规则。
- 无自动连接全部邻地的道路。只有实际补给线及选中行军路线。

建筑和自然物用内置 image_gen 逐件生成，原图在 `source/`，提示词在 [manifest.json](manifest.json) 与 [fort-prompt.json](fort-prompt.json)。`scripts/build-art.mjs` 保留 alpha、去除外部透明留白并统一贴图画布，同时复用之前的士兵绘制来烘焙后坐帧。正式游戏不依赖生成服务，也不依赖脚本使用的本机绘图工具。

像素军队图标参考 [任天堂《Game Boy Wars Advance 1+2》官方单位壁纸](https://www.nintendo.co.jp/n08/bgwj/download/index.html) 的大头盔、明确武器轮廓和阵营标识；图标与零件为本项目重画，没有复制商业游戏贴图。

## 交互与过渡

- 单击工坊仍选择建筑，拖动工坊本体到己方总部／兵营建立补给；两端直接进入建筑，取消额外端口。
- 建线用约 0.65 秒逐段展开；选中地块边缘为每秒一次的缓慢白色闪烁。
- 新入场士兵用约 0.28 秒淡入；阵亡士兵短暂倾倒并用 0.65 秒淡出，收起模型时只淡出。
- 占领底色约 1.2 秒渐变，伴随边缘提示和“领土易主”。
- 战斗近景的军队图标移到地块上缘，减少遮挡士兵；树木、建筑和人物按位置决定前后遮挡。

## 检查方式

`npm test` 检查三档地块数量、尺度、连通性、完整装饰边界、补给端点与展开、试验场入场位置、菜单选择和原有模拟规则。`npm run build` 检查类型与生产构建。

本目录 `game-map-40.png`、`game-map-80.png`、`game-buildings-closeup.png`、`game-combat-closeup.png` 是直接执行正式 `MapScene` 绘图调用生成的离线画面，不是生图，也不是浏览器截图。未代用户操作浏览器；实际拖线、字号、动画和帧率需在游戏中体验。

本轮结果：54 项测试通过，生产构建通过；另检查了正式绘图的全图、近景和阵亡淡出生命周期。
