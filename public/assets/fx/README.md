# Damage particles

Source: Kenney Particle Pack 1.1, already archived at `docs/art-direction/2026-11-ui-study/samples/particle-pack/`. License: CC0; see `License.txt`.

`scripts/build-fx.mjs` resizes `fire_01`, `flame_01`, `smoke_04`, and `light_01` to 128×128, moves grayscale intensity into alpha, and writes white particles for runtime tinting. Four PNGs total 29564 bytes. No generated card art is used by these effects.
