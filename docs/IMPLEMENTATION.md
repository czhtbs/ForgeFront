# 首版实现记录 · 2026-11-06

> 本文记录首版实际实现，不代表最新设计要求。验收后的无库存生产、交互和界面调整见 [升级设计指南](planning/UPGRADE-GUIDE.md)，已实现，本文仍保留升级前的历史记录。

## 当前交付

已实现可启动的桌面单机版本：12/48 地块随机地图、1v1/1v3、三档 AI 反应速度、领土与总部胜负、自动生成/自动装配、四种专用武器与四种效果模块、兵营蓝图、会话/本局蓝图库、10 地块蓝图测试场、资源生产、等级 1–5、补给与部队运输、必经点改线、撤退、并发局部战斗、增援波次、地图缩放和运行状态面板。

实现不使用后端、不保存本地蓝图、不提供暂停与速度控制。没有添加新运行依赖。`sim` 不依赖 Phaser；战斗结果不依赖是否正在观看。

## 规则落地说明

- 未投入局部战斗的士兵只保存数据；观看中的士兵才使用可复用的 Phaser 分层显示对象。机动部队、驻军、运输和战斗中的士兵具有同一套唯一 ID。
- 在途物资固定路径和抵达时间。途中失去路线不撤回；目的地被占领后物资仍到达该地块，由当前占领方获得。敌对部队抵达则加入战斗。
- 兵营按优先蓝图自动装配新兵，消耗已经到达的库存；没有装备时退回基础步枪，不给已有士兵自动换装。装备生产与士兵生成分别付费。
- 毒气与火焰/爆炸排斥，穿透与分裂排斥；默认蓝图按兼容分组拆分。界面中显示全部物资不会绕过实际输入校验。
- 地图节点图使用最短路和可选必经点；当前 UI 设置一个必经点，模拟接受多个。失去必经地块后回到自动最短路。
- 局部地形无阻隔，所以士兵直线接敌，并做小范围分离，不额外引入障碍寻路网格；空间网格用于查找附近目标。
- 穿透使用线段碰撞，爆炸有范围伤害，毒气留下持续区域，分裂伤害附近最多两个额外目标；分裂命中用命中特效表达，不再递归产生弹丸。
- 会话指当前页面运行期。结束一局保留会话蓝图，刷新/关闭页面清空；结束对局时清理本局蓝图。退出训练场不会删除会话蓝图。
- 显示层不会改变伤害判定；被浏览器降频时保留模拟积压并逐批追赶，不静默跳过时间。

## 美术与资源

地图以 C 为方向，用浅色地形、省份边界、阵营覆盖、建筑符号和低干扰补给线表达。当前大陆轮廓采用简化连续形状，随机性主要体现在地块分割；不是对概念图大陆的逐像素复刻。

`public/assets/unit-parts.png` 是 6astra 子智能体用内置生图生成的实际 RGBA 图集，1774×887、4×2 布局。Renderer 按边界向下取整建立帧，不依赖图片恰好整除。

第一行：躯干、头盔、背包、双罐背包；第二行：机枪、狙击枪、火箭筒、喷火器。身体素材朝下，在渲染中转为朝右后随瞄准旋转。无脚部素材或脚步动画，采用滑行。士兵只有静态分层、转向、后坐、枪口火光和命中特效。生成素材的躯干仍有轻微展示透视，需要实机检查组合和缩放效果。

原始生成说明保留在 `docs/art-direction/unit-parts-prompt.txt`。地图与士兵概念图保留在 `docs/art-direction/`，不混入发布包。实际图集放在 `public/assets/`，构建后复制至 `dist/assets/`。

## 验证记录

- `npm test`：16 项通过。包括身份唯一性与确定性检查，以及胜负/撤退/超额幸存者/必经点失守等状态转换。
- `npm run build`：类型检查与 Vite 生产构建通过。Phaser 导致单个脚本超过默认 500 kB 提示阈值；这是构建警告，不是失败。
- `npm run probe`：240 活跃实体 +80 预备兵，分别带穿透、毒气和分裂，模拟 30 秒。当前机器平均每步约 1.1–1.4 ms；这些是 Node 纯模拟数值，不是浏览器整体帧率。
- 48 地块四方 AI 跑完 30 分钟模拟时间，检查资源非负、ID 唯一、驻军和实体上限。最多出现 7 场同时战斗；两方淘汰，剩余两方仍在对抗，说明 30 分钟必定结束的平衡目标尚未达成。
- 本地 HTTP 检查：入口、主模块、UI 模块、渲染模块与图集均返回 200。
- 没有使用 computer use，没有自动操作用户浏览器。画面、交互、浏览器兼容性、真实帧率和玩法节奏留给用户按 [首版试玩计划](planning/PLAYTEST.md) 集中检查。
