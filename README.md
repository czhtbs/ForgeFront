# ForgeFront · 铸造前线

桌面浏览器即时战略游戏，支持单机、装备试验场和最多六阵营的联机对局。Phaser 4 + TypeScript + Vite，联机使用 Node.js 权威服务器和 WebSocket。地图采用明亮浅色浮雕风格、固定平均尺度的随机分割地块；使用重绘建筑、单体地形装饰、模块化像素军队图标及俯视持枪士兵。

## 启动

先安装 Node.js（包含 npm；本项目已在 Node.js 24.16.0 验证）。Clone 仓库后，在仓库所在的上级目录打开终端，执行：

```powershell
cd ForgeFront
npm ci
npm run dev -- --host 127.0.0.1 --port 5180
```

浏览器打开 http://127.0.0.1:5180/ 即可单机游戏。联机开发时，在另一个终端运行 `npm run server`；Vite 会把 WebSocket 转发到本机 5182 端口。首次需要安装依赖，以后无需重复安装；运行时保持终端开启，按 `Ctrl+C` 关闭服务，不要直接双击 `index.html`。无需数据库。

```powershell
npm test
npm run build
npm run probe
```

`test` 检查规则与确定性；`build` 执行类型检查和生产构建；`probe` 检查 240 实体与 48 地块四方 AI，结果不代表浏览器帧率。生产构建可用 `npm run preview -- --host 127.0.0.1 --port 5181` 预览。

完整联机生产包在 `npm run build` 后运行 `npm run server`，打开 http://127.0.0.1:5182/。服务器已在 Linux Node.js 22.23.4 验证。主菜单选择“联机对局”，首位进入者为房主，设置地图与 0–5 名 AI；真人与 AI 合计最多六方，至少两方才能开局。首版只提供一个共享房间，不提供匹配或多房间。

服务器以 30 Hz 统一处理指令，各端执行同一份模拟；每秒校验摘要，失步或后台积压时恢复快照。短时断线自动重连，刷新同一标签页可恢复席位，重复指令不会重复扣费。对局期间新玩家不能加入；所有真人断线 60 秒后回收房间，进程重启不恢复旧局。联机的“结束本局”为本方投降，其他存活玩家继续比赛。

正式入口：[CS 中转站 · 铸造前线](https://czhtbs.ykcryobs.cn/forgefront)，位于“其他 → OpenFront”下方，沿用中转站登录和临时玩家。部署位置、回退方法及验证记录见 [联机游戏设计](docs/planning/联机游戏设计.md)。

## 第一次试玩

1. 菜单进入对局，可选 1–5 名 AI；小／中／大地图分别为 40／60／80 地块，地块和单位尺度相同。出生点按阵营数向内陆分散，优先选择不接触海岸的地块，每方保留相邻金矿。
2. 每方开局有 40 名步枪军队、总部兵营和相邻金矿。可直接把军队图标左拖到中立地块派兵，也可先框选多组，再拖动其中任意一组统一下令。
3. 部队可沿己方或中立地区前进，不能穿过敌占中间地区；跨入敌方或中立目标地块后，从入口逐个展开战斗模型。途经中立地块不自动占领；堡垒血量归零后，地面部队接近据点才能占领。
4. 建设发射器工坊，选择步枪或剑。先选中工坊并松手，再从建筑拖线到兵营；配件工坊可随后接入。不再建设弹药工坊。
5. 兵营持续生成肉人，直到本地人数与在途肉人预留名额合计达到 60。装好一件武器即可战斗；只接配件仍不能战斗。
6. 已装备但未出征的士兵可以继续追加兼容配件；作为军队第一次派出后装备永久固定，返回兵营也不再装配。
7. 先选中兵营，再拖到另一己方兵营，建立肉人中转线。源兵营停止本地装配，只送未装备肉人与全部收到的装备；肉人到达后仍可装配。
8. 用地面部队占领敌方总部取得胜利，查看战报并返回菜单。

## 生产与供给

- 黄金只用于建设、升级建筑，生成肉人和装配不花黄金。
- 一个兵营可以同时存在不同完成程度的配置。各装备按实际抵达的速率独立装配，优先补齐已有装备较多的士兵；原装备不会被重复消耗或整套覆盖。
- 输入必须整组兼容：步枪和剑不能混入同一生产配置；近战行为配件只允许穿透。建立冲突连线或切换出冲突的工坊产出会被直接拒绝，包括对下游中转兵营造成的冲突，原线路和产出保持不变。
- 武器和配件供给速度不同时，会同时存在未装备肉人、基础装备士兵与带配件士兵。晚接入的兼容效果继续加到未出征士兵身上，已有部件不会浪费。
- 只接配件时肉人不能作为军队出发，但可沿兵营运输线中转。武器与配件可先后抵达。
- 无装备库存。各项供给只累积正在装配的不足一件进度；没有可装配人员时该项供给浪费，不积攒供给供未来爆发式生产。武器装好后不替换，兼容效果只追加。
- 工坊的所有已建立连接等分总产能；不需要或被切断线路的份额不转给其他线路。删除连接后才重新均分。工坊或兵营失守时，其端点连接自动销毁并重新均分；仅途经地块失守仍按原通路重算规则处理。
- 兵营／总部可连接多个己方兵营，并支持 A→B→C 连续中转，禁止循环。存在出口时停止本地装配；收到的装备逐项按全部出口等分，装备线与肉人共用路径，兵营之间只显示一根肉人线。
- 建线前已有和之后生成的未装备肉人按出口轮流均分，已经有武器的人员留在源兵营。满员、瘫痪或断线分支的肉人留在源头，不转给其他分支；装备份额仍按无库存规则处理。
- 在途肉人预留目标容量，避免多条运输线同时送满。若普通军队在途中占用了名额，已到达的肉人等待空位；普通军队增援与战斗幸存者仍保留原有超额容纳规则。
- 删除兵营的全部出口后恢复本地装配。路径点编辑同时约束后续肉人与装备运输；已经发出的运输继续使用出发时的路线，途中失守仍按现有重算规则处理。
- 满员停止生成肉人，接收且没有转运出口的兵营仍可继续装配。
- 未装备肉人不显示地图图标；顶部和战报只统计已装备兵力。建筑右栏只显示血量、部队数量与等级；兵营另显示所有尚未出征、仍有装配资格的人员总数，工坊另显示当前产出。

## 装备与炮击

发射器工坊与配件工坊各花费 110 金，只生产对应类别的装备。发射器工坊提供步枪和剑，分别沿用“通用发射器＋实体弹”“剑柄＋剑刃”的攻击行为和数值，激光枪已移除；弹体只作为内部攻击类型，不再单独生产或运输。

近战只按范围和间隔判定命中，基础单目标，穿透最多命中三人；炸药、电弧、燃烧和冷凝仅追加命中者的单兵伤害。其余八种行为配件为远程独占。

近战剑具有约 0.25 秒的基础挥舞动画；普通剑击建筑只扣血，不生成远程黄色着弹点。军队图标使用持剑画像，不叠加“剑”字；六个阵营均有可用颜色和士兵贴图。

远程支持穿透、弹跳、分裂、返航、追踪、滞留、留痕、延时、抛射。留痕需要效果配件，延时需要末端效果。分裂产生真实分支；电弧分裂不会复制承载弹体。

装有抛射的部队使用普通军令箭头指向敌方地块或部队；射程内就地展开，射程外自动接近后展开。射程为以部队中心计算的 65–330 地图单位，保留最小射程与近敌压制。选中时显示射程圈，不再有独立炮击按钮或选点模式。移动到己方地块会取消炮击。每次发射重新瞄准所选敌军的真实当前位置，目标死亡后改攻组内幸存者；追踪配件仍只负责炮弹发射后的空中修正。

炮击影响范围内所有敌方人员，包括肉人、预备兵与行军部队，友军免伤。建筑零血后停产但保留归属，脱离攻击八秒后自动修复；只有地面部队接近零血堡垒才能占领。

## 地图操作

| 操作 | 效果 |
| --- | --- |
| 左键地块或建筑 | 单击只选择，不显示箭头；右栏覆盖地图，不移动镜头 |
| 从地面左键拖动 | 框选范围内的己方部队整组，包括行军部队；不选地块或敌军，不派兵 |
| 直接左键拖动军队图标 | 无须预选；拖未选中的组只指挥该组，拖已选中的组指挥全部已选部队；长按约 280 毫秒或拖动超过 6 像素显示军令 |
| 按住 Shift 拖动军队箭头 | 派出所选人数的一半，奇数向上取整；选择跟随派出的人。可拆分正在行军的部队，普通拖动仍派出全部 |
| Ctrl 点击军队图标 | 添加到选择，再点同一组取消；拖动任一已选图标统一下令 |
| Ctrl 框选 | 把框内己方整组加入已有选择 |
| 直接拖动行军部队图标 | 从当前位置改道，选择会随士兵保留，不需要等待抵达 |
| 将交战中的己方组拖到相邻己方地块 | 撤退该组 |
| 先选中工坊，再从建筑拖到己方兵营 | 建立武器或配件供给线 |
| 先选中兵营／总部，再从建筑拖到另一己方兵营 | 建立肉人与装备中转线；建筑拖动不派军队 |
| 从抛射部队拖箭头到敌方地块或部队 | 射程外自动接近，射程内停下展开；每次发射重新瞄准当前目标 |
| 将炮兵拖到己方地块 | 取消炮击并移动 |
| 选中工坊或兵营 | 关联线路加粗、共线路段分开以便选中 |
| 拖动高亮线段 | 插入路径点；松回原线上不新增 |
| 拖动路径点 | 移动该点，保留其他点 |
| 选中点后 Delete / “删除路径点” | 删除此点 |
| 选中线路后地图上方操作 | 删除连线或恢复最短路 |
| 右键单击 | 取消选择 |
| 右键拖动 | 平移地图，保留已有选择，不发军令 |
| 滚轮 | 以鼠标位置为中心缩放 |
| H / 全图 | 返回全图 |
| Esc | 取消拖动与选择 |
| F3 | 查看运行状态 |

游戏页面统一拦截右键菜单，包括侧栏、线路工具和菜单覆盖层。滚轮缩放会即时刷新相机矩阵，以光标下的地图位置为固定点，平移、改变窗口尺寸或连续滚轮事件后仍保持该位置。

Edge 内置鼠标手势由浏览器控制，网页不能可靠禁用。使用右键拖地图前，在 Edge 地址栏打开 `edge://settings/mouseGesture`，把 `czhtbs.ykcryobs.cn` 加入不使用鼠标手势的网站列表；本地试玩可加入 `127.0.0.1`。这是本机浏览器设置，游戏不会修改其他网站的手势或全局浏览器设置。[Microsoft：鼠标手势](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-policies/MouseGestureEnabled)

默认视图显示已装备军队图标和人数。步兵在屏幕上的主体达到 6 像素时开始渐显，到 10 像素时完整显示，死亡碎片和战斗特效使用同一缩放过渡；视图不会改变战斗模拟。非战斗驻军和行军部队仍使用图标。跨入敌方或中立目标地块后，各阵营每 0.2 秒投入一名士兵；已经能攻击时不再强制向前挤出入口，否则继续接敌。未入场人员不会射击。同目标友军横向分散，无目标时不会主动挤向地块中心。占领完成后收起模型，若仍有残敌则保留军队和交战数据。

地图轮廓由种子在长方形、椭圆和不规则岛屿之间选择，同时随机决定长宽比例和横纵方向；相同种子可以复现。地块采用不规则 Voronoi 分割，共享边界与海岸转换为轻微波浪曲线；绘制、选中与地块进入判定共用同一边界，平均面积固定约 9353 平方地图单位；40／60／80 地块只改变地图范围。人物主体为 2.7 地图单位，战斗间距目标为 3.24，建筑为 22–36。步枪的本地射程为 38.88，近战范围为 5.76；行军和战场移动速度为 12 单位/秒。冷凝可减速并短暂冻结远程命中的敌人。进入战场的各阵营仍每 0.2 秒投入一人，未入场人员不射击。

阵亡时短促喷溅血点，头盔、武器和躯干部件击飞、落地；残留最多 5 秒后清理，战斗结束不会令这些效果突然消失。

选中地块以白色边缘每秒缓慢闪烁；占领时归属底色渐变并显示边界反馈。地表有连续的浅色草地、沙土、颗粒和地势明暗。树木和山峰为少量单体贴图：普通地块 0–1 个，山地最多 2 个，森林最多 5–7 棵；整张贴图不会跨出所属地块。建筑不再带阵营色椭圆底座。地图没有自动铺满的邻接道路，只显示已建立的补给线和选中行军路线。补给线从工坊建筑逐段展开到兵营建筑。选中工坊后，重合线路平行展开并标号；侧栏线路编号可逐条选择，只有所选线路显示可拖动路径点。每条线只有一个白色运输点沿整条路径连续移动。

地图不再显示地名。地图图标按已装备配置分组，未装备肉人不计入图标；右侧只保留建筑数据与操作控件，教学和规则说明放在新手教程或文档中。行军图标单独显示在途人数。军令箭头带有弧度、厚度、高光和地面投影；进攻为红色，友方移动为黄色。工坊拖线进入兼容的己方兵营／总部地块后吸附到建筑中心。

## 建筑面板与图卡

以下 UI 和特效已接入正式对局与装备试验场，由 `src/main.ts` 启动的 `GameUI` 和 `MapScene` 直接使用；生产构建包含 SVG 图卡及特效贴图，无需打开美术评审页或启用额外开关。

建筑名称右侧直接显示升级按钮，费用不足或达到 5 级时禁用；无需切换分页。已建建筑面板不再重复显示建筑大图。

空地使用四张“名称＋建造价格＋静态示意图”卡片；发射器工坊使用两张武器卡片，配件工坊使用十三张配件卡片。全部图卡采用紧凑两列排布。点击图卡即选择产出，当前项用边框与勾选标记表示。列表纵向滚动，数据刷新保留滚动位置。

对局中不显示教学段落、操作提示、生产周期或成功消息。失败反馈只显示红色标记，具体原因保留为无障碍标签。原有地图指挥、产线编辑和炮击功能保留。

游戏图卡使用 `public/assets/cards/` 中的 SVG，建筑图卡没有底部阴影。AI 生图原始 PNG、600×300 无损 PNG 和 WebP 分别保存在 `docs/art-direction/2026-11-ui-refinement/` 下的 `generated-originals/`、`generated-png600/`、`generated-webp600/`，不随游戏打包。

[画质与体积对照页](docs/art-direction/2026-11-ui-refinement/comparison.html)包含逐张对比、原始 PNG、同尺寸无损 PNG、WebP 和 gzip 估算统计。19 张 SVG 共 407571 字节，生图 WebP 共 321930 字节；其中建筑 SVG 内嵌 PNG，装备卡和建筑卡需要分开比较。

炸药使用闪光、火团、冲击波和烟尘；电弧弹从飞行开始即显示抖动分叉电线；燃烧在圆形范围内分散八簇小火苗；冷凝在圆形范围内飘落雪花。近战附魔同步使用对应命中特效，伤害规则保持原样；其余配件沿用原行为和绘制。四张本地 CC0 粒子贴图共 29564 字节，运行时复用图像对象并剔除视野外贴图。


[四种特效前后动态对比](docs/art-direction/2026-11-damage-fx/index.html)保留旧版供比较。步枪、全部 13 种配件及全配件组合均提供 30 帧/秒循环 GIF，可在图卡对照页逐项播放。动画复用实际战斗逻辑与 MapScene 离线绘制，不是实机录像。

## 装备试验场

从菜单进入约 10 地块的试验场。己方空地可免费建设工坊与兵营，两类工坊分别提供武器和配件，使用与正式对局相同的连线规则。选中己方兵营后可测试当前配置，支持 40、120、160 对等规模；试验直接生成所选配置，与正式战斗使用同一套模拟；抛射配置自动部署到另一地块进行炮击。

没有蓝图编辑器、默认搭配、装备库存、账号、云存储或本地存档。刷新页面开始新会话。
