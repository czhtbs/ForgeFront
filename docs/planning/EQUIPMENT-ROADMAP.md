# ForgeFront 未来装备与跨地块火力计划

更新日期：2026-11-10。

状态：本计划已实现。当前包括两类工坊、两种成品武器、兵营中转、十三种配件、简化近战，以及迫击炮和导弹炮击。浏览器操作与长期平衡仍需试玩。

## 已确认的装备设计

装备由成品武器和配件组成，弹体是武器自带的攻击类型，不再作为独立资源。工坊连线决定装配结果，不增加逐部队编辑的行为蓝图，也不要求观察员、制导员或供能单位才能形成战斗力。

除步枪、剑外，能用现有配件组合得到的武器只作为组合示例，不新增独立发射器。

### 工坊与装配

| 建筑 | 可生产内容 | 建造费用 |
| --- | --- | --- |
| 发射器工坊 | 步枪、剑 | 110 金 |
| 配件工坊 | 四种效果配件与九种行为配件 | 110 金 |

装好一件武器即可战斗，配件可在武器之前或之后抵达，武装出征前自动追加兼容配件。作为军队首次出征后不再装配，返回兵营也不例外。未装备肉人可以中转到另一兵营并继续装配。已装好的装备不会因断线消失。

每类工坊只允许选择该类产出。多种武器不能混入同一生产配置。保留无库存、产能均分、满员继续补装的规则；中转兵营停止本地装配。

### 成品武器与原攻击组合

| 攻击类型 | 成品武器 | 原攻击组合 | 基本行为 |
| --- | --- | --- | --- |
| 远程 | 步枪 | 通用发射器＋实体弹 | 实体弹发射后独立运动 |
| 近战 | 剑 | 剑柄＋剑刃 | 进入攻击范围后，按攻击间隔命中敌人 |

内部沿用原来的攻击组合、数值和动画，只合并生产与装配资源。不另设迫击炮发射器或导弹发射器。

发射频率、初速度、基础威力和基础攻击距离为固定数值，攻击行为由配件改变。

四种效果配件全部通用。九种行为配件中，仅穿透支持近战，其余八种均为远程独占。

### 兵营中转

兵营和总部可以连接多个己方兵营，支持连续中转，禁止循环。存在出口时停止本地装配，只自动输送未装备肉人，已有武器人员与普通军队留在源头。建线前后的肉人均可转运，并保留已装配的配件及到达后的补装资格。

肉人按出口轮流均分；收到的每种装备按全部出口等分，沿同一条肉人路线继续运输。兵营之间只画肉人线，不再画各项装备线；新增／删除装备输入或修改肉人路径时，后续装备运输随之更新，不复制产能。上游连线和工坊产出修改会校验全部下游的装备兼容性。

目标满 60 人时，该分支肉人留在源兵营，不转给其他分支；在途肉人预留目标容量。普通军队到达挤占名额时，已经到达的肉人等待空位。装备仍无库存，无法使用的份额浪费。已发出运输不会因删线而消失；目的地被占领后抵达的肉人转归当前占领方，不作为作战部队参战。删除源兵营全部出口后恢复本地装配。

### 效果配件

| 配件 | 远程作用 |
| --- | --- |
| 炸药 | 攻击载体终止时释放范围爆炸 |
| 电弧 | 攻击载体存在期间，周期性向附近敌人放电 |
| 燃烧剂 | 在命中位置产生持续燃烧 |
| 冷凝剂 | 命中积累寒冷，产生减速，达到阈值后短暂冻结 |

### 行为配件

| 配件 | 适配范围 | 已确认的职责 |
| --- | --- | --- |
| 穿透 | 通用 | 命中后继续执行攻击，命中次数耗尽才终止 |
| 弹跳 | 远程独占 | 碰撞后改变方向，继续攻击 |
| 分裂 | 远程独占 | 将当前输出分成多个分支，分摊威力 |
| 返航 | 远程独占 | 到达行程末端后返回 |
| 追踪 | 远程独占 | 攻击过程中逐渐调整方向，追向目标 |
| 滞留 | 远程独占 | 到达终点或撞停后保留一段时间，继续接触攻击或释放持续效果 |
| 留痕 | 远程独占 | 沿运动路径间隔留下弱化的附加效果 |
| 延时 | 远程独占 | 推迟末端效果的释放时刻 |
| 抛射 | 远程独占，本次用于实体弹 | 统一提供跨地块攻击能力；弹体越过沿途地面单位，到落点才进行地面命中 |

这两个分组只用于整理目录，不要求每组选一个固定卡槽。多个配件通过固定规则自动组合，不让玩家编辑执行顺序。

分裂作用于当前正在输出的攻击：无附加效果时分裂基础攻击；输出电弧时分裂电弧，不同时复制承载电弧的回旋镖。分支不递归分裂。穿透逐次衰减，分裂分摊威力；穿透最多命中三人，后续威力乘以 0.7；弹跳最多两次；分裂为三份；滞留两秒，延时 0.9 秒。配件不重复装配，不另设数量卡槽。

## 近战规则

士兵进入攻击范围后，按攻击间隔命中一名敌人；穿透允许同次攻击命中范围内多个敌人。只做攻击范围与命中判定，不计算剑刃位置或挥砍轨迹。

炸药、电弧、燃烧剂、冷凝剂均作为附魔，为本次命中的每个敌人额外结算对应类型伤害。炸药同样只对被命中的单兵造成额外伤害。

## 跨地块炮击

抛射部队与普通军队一样拖箭头指向敌方地块或敌军图标。目标超出射程时自动接近，射程内停下展开；移动中的炮兵也可就地展开。选中时显示以部队中心计算的最小和最大射程圈。移动到己方地块取消炮击，不再有独立炮击按钮或选点模式。

| 组合 | 行为 |
| --- | --- |
| 步枪、抛射、炸药 | 迫击炮，锁定落点后飞行，移动目标可以躲开 |
| 步枪、抛射、追踪、炸药 | 导弹，在飞行途中有限度地修正方向 |

炮击距离为 65–330 地图单位。按部队中心判断距离；目标过近或附近 65 单位内有已装备敌军时不能开火，目标超过射程则自动接近。装有抛射的单位卷入近距离战斗后没有普通直射攻击，只能依靠其他部队解围或撤退。

抛射仅支持实体弹。未装抛射的攻击只影响本地战场。空中弹药越过地面单位，到落点后才接触敌人；穿透和弹跳可以继续修正落地后的攻击。已发射弹药独立存在，不随发射者死亡、源地失守或局部战斗结束而消失。

每次发射重新获取所选部队的当前位置，优先攻击仍存活的目标；空中追踪仍由追踪配件提供。炮击按实际坐标影响敌方驻军、机动兵、预备兵、肉人和行军部队，友军免伤。可以炮击己方地块里的敌军。燃烧与爆炸可损伤建筑；建筑瘫痪不剥夺驻军的作战能力。

## 破坏与占领

建筑血量为零后停止生产、招募、装配和金币收入，相关供给线暂停。原地块归属不变。停止遭受攻击八秒后，以每秒 50 血自动修复，恢复正血量后恢复生产。

地面部队接近零血量堡垒后才能占领，地块恢复 1000 血并转移归属。总部只有被地面占领后才触发阵营失败；炮击不能隔空取得地块或直接赢得对局。

## 实现与验证

装备目录与兼容检查在 [equipment.ts](../../src/content/equipment.ts)，装配与占领在 [world.ts](../../src/sim/world.ts)，近战和局部索敌在 [combat.ts](../../src/sim/combat.ts)，弹体、配件、炮击和范围伤害在 [attacks.ts](../../src/sim/attacks.ts)。AI 使用同样的装配、炮击与撤退规则。

试验场按两类工坊建立配置。普通装备进入局部战斗；抛射装备部署在射程内的另一地块，执行真实炮击。

自动检查覆盖成品武器装配、后接配件、出征固定、工坊产出限制、兵营分流与连续中转、满员保留、装备守恒、下游冲突、循环拒绝、部队直接拖令、框选后拖令与建筑预选连线，以及原有近战、配件、炮击和占领规则。炸药、电弧、燃烧、冷凝采用新的分层动画，包含近战命中，但不改变伤害；其他特效保持原样。建筑面板使用简洁数据、直接升级和静态 SVG 图卡选择，AI 版本保存在本地文档目录，详见 README。
