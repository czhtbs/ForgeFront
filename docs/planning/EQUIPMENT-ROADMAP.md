# ForgeFront 未来装备与跨地块火力计划

更新日期：2026-11-09。

状态：本计划已实现。当前包括三类工坊、双条件装配、十三种配件、简化近战，以及迫击炮和导弹炮击。数值为首轮实现值，浏览器操作与长期平衡仍需试玩。

## 已确认的装备设计

装备由发射器、基础弹体和配件组成。工坊连线决定装配结果，不增加逐部队编辑的行为蓝图，也不要求观察员、制导员或供能单位才能形成战斗力。

能用现有部件组合得到的武器，只作为成品名称或组合示例，不新增独立的基础发射器。

### 工坊与装配

| 建筑 | 可生产内容 | 建造费用 |
| --- | --- | --- |
| 发射器工坊 | 通用发射器、剑柄 | 110 金 |
| 弹药工坊 | 实体弹、射束、剑刃 | 110 金 |
| 配件工坊 | 四种效果配件与九种行为配件 | 110 金 |

发射器与弹药分别装配，任一缺失都仍是肉人，不能战斗或调动。配件可在基础部件之前或之后抵达，首次离营前自动追加兼容配件。首次离营后的军队不再装配，返回兵营也不例外。已装好的部件不会因断线消失。

每类工坊只允许选择该类产出。剑柄只配剑刃，通用发射器只配远程弹药；多种发射器或弹药不能混入同一生产配置。保留无库存、产能均分、满员继续补装的规则。

### 发射器与基础弹体

| 攻击类型 | 发射器 | 基础弹体 | 基本行为 |
| --- | --- | --- | --- |
| 远程 | 通用发射器 | 实体弹、射束 | 实体弹发射后独立运动；射束与发射口相连，输出停止后消失 |
| 近战 | 剑柄 | 剑刃，仅此一种 | 进入攻击范围后，按攻击间隔命中敌人 |

“通用发射器”“远程发射器”“通用远程发射器”此前指同一类型，统一使用“通用发射器（远程）”与“剑柄（近战）”。不另设迫击炮发射器或导弹发射器。

发射频率、初速度、基础威力和基础攻击距离为固定数值，攻击行为由配件改变。

四种效果配件全部通用。九种行为配件中，仅穿透支持近战，其余八种均为远程独占。

### 效果配件

| 配件 | 远程作用 |
| --- | --- |
| 炸药 | 攻击载体终止时释放范围爆炸 |
| 电弧 | 攻击载体存在期间，周期性向附近敌人放电 |
| 燃烧剂 | 在命中位置产生持续燃烧 |
| 冷凝剂 | 命中积累寒冷，产生减速，达到阈值后短暂冻结 |

### 行为配件

| 配件 | 适配范围 | 已确认的职责 |
| --- | --- | --- |
| 穿透 | 通用 | 命中后继续执行攻击，命中次数耗尽才终止 |
| 弹跳 | 远程独占 | 碰撞后改变方向，继续攻击 |
| 分裂 | 远程独占 | 将当前输出分成多个分支，分摊威力 |
| 返航 | 远程独占 | 到达行程末端后返回 |
| 追踪 | 远程独占 | 攻击过程中逐渐调整方向，追向目标 |
| 滞留 | 远程独占 | 到达终点或撞停后保留一段时间，继续接触攻击或释放持续效果 |
| 留痕 | 远程独占 | 沿运动路径间隔留下弱化的附加效果 |
| 延时 | 远程独占 | 推迟末端效果的释放时刻 |
| 抛射 | 远程独占，本次用于实体弹 | 统一提供跨地块攻击能力；弹体越过沿途地面单位，到落点才进行地面命中 |

这两个分组只用于整理目录，不要求每组选一个固定卡槽。多个配件通过固定规则自动组合，不让玩家编辑执行顺序。

分裂作用于当前正在输出的攻击：无附加效果时分裂基础攻击；输出电弧时分裂电弧，不同时复制承载电弧的回旋镖。分支不递归分裂。穿透逐次衰减，分裂分摊威力；穿透最多命中三人，后续威力乘以 0.7；弹跳最多两次；分裂为三份；滞留两秒，延时 0.9 秒。配件不重复装配，不另设数量卡槽。

## 近战规则

士兵进入攻击范围后，按攻击间隔命中一名敌人；穿透允许同次攻击命中范围内多个敌人。只做攻击范围与命中判定，不计算剑刃位置或挥砍轨迹。

炸药、电弧、燃烧剂、冷凝剂均作为附魔，为本次命中的每个敌人额外结算对应类型伤害。炸药同样只对被命中的单兵造成额外伤害。

## 跨地块炮击

选中驻停且装有抛射的部队，点击侧栏“炮击”，再点击地图落点或敌军图标。点击图标会使用实际士兵位置。部队持续原地开火，移动指令和“停止炮击”会取消该命令。选点时显示最小和最大射程圈。

| 组合 | 行为 |
| --- | --- |
| 通用发射器、实体弹、抛射、炸药 | 迫击炮，锁定落点后飞行，移动目标可以躲开 |
| 通用发射器、实体弹、抛射、追踪、炸药 | 导弹，在飞行途中有限度地修正方向 |

炮击距离为 65–330 地图单位。目标过近、超过射程，或发射者周围 65 单位内有已装备敌军时不能开火。装有抛射的单位卷入近距离战斗后没有普通直射攻击，只能依靠其他部队解围或撤退。

抛射仅支持实体弹。未装抛射的攻击只影响本地战场。空中弹药越过地面单位，到落点后才接触敌人；穿透和弹跳可以继续修正落地后的攻击。已发射弹药独立存在，不随发射者死亡、源地失守或局部战斗结束而消失。

炮击按实际坐标影响敌方驻军、机动兵、预备兵、肉人和行军部队，友军免伤。可以炮击己方地块里的敌军。燃烧与爆炸可损伤建筑；建筑瘫痪不剥夺驻军的作战能力。

## 破坏与占领

建筑血量为零后停止生产、招募、装配和金币收入，相关供给线暂停。原地块归属不变。停止遭受攻击八秒后，以每秒 50 血自动修复，恢复正血量后恢复生产。

地面部队接近零血量堡垒后才能占领，地块恢复 1000 血并转移归属。总部只有被地面占领后才触发阵营失败；炮击不能隔空取得地块或直接赢得对局。
