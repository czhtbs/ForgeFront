# ForgeFront · 铸造前线

桌面浏览器单机即时战略游戏。Phaser 4 + TypeScript + Vite，无后端。地图采用亮色军事地图；近景使用正俯视据点和分层士兵。

## 启动

本机依赖已安装，在项目目录执行：

```powershell
npm run dev -- --host 127.0.0.1 --port 5180
```

打开终端显示的本地地址，通常为 http://127.0.0.1:5180/ 。不要直接双击 `index.html`。

```powershell
npm test
npm run build
npm run probe
```

`test` 检查规则与确定性；`build` 执行类型检查和生产构建；`probe` 检查 240 实体与 48 地块四方 AI，结果不代表浏览器帧率。生产构建可用 `npm run preview -- --host 127.0.0.1 --port 5181` 预览。

## 第一次试玩

1. 菜单进入对局，选择 12 地块、1 名 AI。
2. 每方开局有 40 名已装备步枪的军队、总部兵营和相邻金矿。左键从总部地块或军队图标拖到中立地块，松开派兵。
3. 部队可沿己方或中立地区前进，不能穿过敌占中间地区；跨入敌方或中立目标地块后，从入口逐个展开战斗模型。途经中立地块不自动占领；目标堡垒血量归零后才占领目标。
4. 在新占领地区建设工坊，选择机枪产出。从地图上的工坊圆形输出端拖到己方兵营，建立补给线。
5. 兵营持续生成肉人，直到本地人数达到 60。未装备肉人不战斗、不能调动；供给抵达后逐人装配。
6. 已装备但未离营的肉人可以重新装配；第一次派出后成为军队，装备永久固定，返回兵营也不再装配。
7. 摧毁敌方总部取得胜利，查看战报并返回菜单。

## 生产与供给

- 黄金只用于建设、升级建筑，生成肉人和装配不花黄金。
- 一个兵营只有一种配置，由全部输入线路决定。多个主武器或不兼容效果同时接入，停止装配并显示冲突；肉人仍按容量生成。
- 无装备连线或只有效果模块时，肉人等待主武器，不自动获得步枪。
- 无装备库存。装配速率取兵营产能和各必需装备输入速率的最小值；无法使用的供给浪费。
- 工坊的所有已建立连接等分总产能；满员、冲突或被切断线路的份额不转给其他线路。删除连接后才重新均分。工坊或兵营失守时，其端点连接自动销毁并重新均分；仅途经地块失守仍按原通路重算规则处理。
- 满员只停止生成肉人，已有肉人仍能装配。额外援军和战斗幸存者不会被上限删除。
- 未装备肉人用灰色身体显示，已装备肉人有金色状态点；军队有武器而无肉人状态点。点击图标可查看状态和人数。

## 地图操作

| 操作 | 效果 |
| --- | --- |
| 左键地块或建筑 | 单击只选择，不显示箭头；右栏覆盖地图，不移动镜头 |
| 从地块左键拖到另一地块 | 派出当地全部已装备人员，无须提前选中 |
| 点击军队/肉人图标，再拖动该图标 | 单击选择，长按约 280 毫秒或拖动超过 6 像素才显示军令；未装备肉人不能出发 |
| Ctrl 点击军队图标 | 添加到选择，再点同一组取消；拖动任一已选图标统一下令 |
| 拖动行军中的装备图标 | 从当前位置改道，选择会随士兵保留，不需要等待抵达 |
| 交战中的己方组拖到相邻己方地块 | 撤退该组 |
| 从工坊圆形输出端拖到己方兵营 | 建立装备线 |
| 选中工坊或兵营 | 关联线路加粗、共线路段分开以便选中 |
| 拖动高亮线段 | 插入路径点；松回原线上不新增 |
| 拖动路径点 | 移动该点，保留其他点 |
| 选中点后 Delete / “删除路径点” | 删除此点 |
| 选中线路后地图上方操作 | 删除连线或恢复最短路 |
| 右键拖动 | 平移地图，不发军令 |
| 滚轮 | 以鼠标位置为中心缩放 |
| H / 全图 | 返回全图 |
| Esc | 取消拖动与选择 |
| F3 | 查看运行状态 |

非战斗的肉人、驻军和行军部队只显示装备图标与人数。跨入敌方或中立目标地块后，各阵营每 0.2 秒展开一名战斗士兵；进攻部队从入口分散出现，先向前走出入口，再按射程接敌。未入场人员只计入图标，不会隐形射击。占领完成立即收起模型和战斗特效，重新用图标表示；若还有残敌，保留军队与交战数据，直到该场战斗结束。

人物主体为 9 地图单位；步枪、机枪、火箭筒、狙击枪的射程分别为 90、108、135、162 地图单位，喷火器为 45。行军与战场移动仍为 12 地图单位/秒，压制会减速。双方同时进入中立地块时优先互相接战；敌方还有待入场人员时，不绕过他们主动攻击堡垒。堡垒仍可能受到爆炸附带伤害。

地图不再显示地名。地图图标人数表示实际人员数量，肉人和军队分组；右侧的“件/秒”是供给速率，不是人数。行军图标单独显示在途人数。

## 装备试验场

从菜单进入约 10 地块的试验场。己方空地可免费建设工坊与兵营，工坊可选全部装备，使用与正式对局相同的连线规则。选中己方兵营后可测试当前配置，支持 40、120、160 对等规模；试验直接生成所选配置，与正式战斗使用同一套模拟。

没有蓝图编辑器、默认搭配、装备库存、账号、云存储或本地存档。刷新页面开始新会话。
