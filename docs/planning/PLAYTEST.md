# 首版集中试玩清单

> 历史验收计划。2026-11-06 用户在 1 AI、12 地块场景完成验收，提出的问题与新验收标准统一见 [升级设计指南](UPGRADE-GUIDE.md)。以下旧规则检查项保留用于追溯，不作为新版标准；未据此勾选尚未逐项确认的 48 地块、1v3 和性能检查。

建议在桌面 Chrome 或 Edge、1280×720 或更高窗口尺寸下检查。先用 12 地块验证操作，再看训练场动画，最后玩一局 48 地块。复现问题时记录地图种子、游戏时间、地块名称和操作；必要时附截图。

## 1. 启动与地图（约 3 分钟）

- [ ] 页面正常显示，无白屏；主界面可选择 12/48 地块、1/3 名 AI、难度与种子。
- [ ] 地图是亮色连续大陆、不规则地块，阵营边界与地块细边界容易区分。
- [ ] 总部与己方初始金矿相邻，其他地块最初为中立。
- [ ] 右侧面板约占 20%，文字、按钮和滚动内容没有截断或遮挡地图。
- [ ] 左键选择、地图拖动、滚轮缩放和 H 返回全图工作正常；右键不弹浏览器菜单。
- [ ] 重新开始同种子、同规模的对局，地图和初始位置一致。

## 2. 自动生成与经济（约 5 分钟）

- [ ] 无需点击训练，兵营兵力随时间增长；界面不存在训练按钮或训练队列。
- [ ] 金矿持续增加黄金，生成士兵、生产装备、建设和升级会扣除对应黄金。
- [ ] 驻军达到 60 后停止自动生成；派走部队后恢复，升级不会提高驻军上限。
- [ ] 建造和升级反馈明确，建筑最高 5 级。
- [ ] 金矿、兵营、工坊的名称、地图图标和等级能看清。

## 3. 扩张、运输与自动装配（约 8 分钟）

- [ ] 从总部派兵到相邻中立地块，部队经过运输时间后才到达。
- [ ] 对非相邻敌地不能直接进攻；己方连通地块可自动寻路调动。
- [ ] 占领要等地块耐久归零，完成后耐久回满。
- [ ] 在新地块建工坊，选择机枪并连接到总部，地图出现补给线和白色流动点。
- [ ] 装备经过运输时间后入库，新生成士兵自动装配；已有士兵保持原装备。
- [ ] 更改工坊产出、提高工坊等级后，输入说明和生产速度跟着改变。
- [ ] 多条线路重叠时，可在列表分别选中并高亮；能删除单条路线。
- [ ] 选中工坊/兵营和单条路线后，拖动线路到己方地块可改变必经点；恢复最短路有效。
- [ ] 路线穿过交战地块时显示延迟；失去通路后显示切断。
- [ ] 已经发出的物资继续到达；切断补给不会清除已装备士兵的武器。
- [ ] 必经地块失守后，会重新尝试最短路。

## 4. 蓝图与生命周期（约 5 分钟）

- [ ] 从兵营蓝图视图进入编辑器，编辑仍在右侧；没有跳到独立页面。
- [ ] 默认筛选我方正在生产的物资，「显示全部装备」可见其他选项。
- [ ] 选择没有实际输入的装备不能保存，原因明确；显示全部不绕过输入约束。
- [ ] 「毒气＋火焰」「毒气＋爆炸」「穿透＋分裂」不能保存。
- [ ] 其他高成本组合可保存，显示完整产出成本。
- [ ] 清除默认配置、恢复默认、新建、复制编辑、优先装配均工作正常。
- [ ] 本局蓝图可套用到其他有相应输入的兵营。
- [ ] 训练场保存的会话蓝图在结束训练场、开始新局后仍存在。
- [ ] 结束对局后本局蓝图消失；刷新页面后会话蓝图也消失。

## 5. 士兵与战斗观感（优先检查）

先在主界面的蓝图训练场建立机枪、狙击、火箭、火焰四种蓝图，分别测试 40 对 40。

- [ ] 放大后看见实际士兵，缩小后变为部队/战斗概览，不会同时画出双份部队。
- [ ] 士兵采用滑行移动，没有脚步动画；这种表现是否可以接受？
- [ ] 身体、头盔、武器和背包组合自然；旋转后没有明显错位、脱离或武器浮空。
- [ ] 机枪、长狙击枪、粗火箭筒、火焰喷口能在实际缩放下区分。
- [ ] 青/红阵营在近景仍能看清，不依赖细小文字辨认。
- [ ] 瞄准转向、枪口火光、后坐和弹道衔接自然；不会有明显反向开枪。
- [ ] 机枪射速与压制、狙击射程、火箭爆炸、火焰近距离范围攻击有可感知区别。
- [ ] 穿透、爆炸、毒气和分裂模块效果能被识别；特效不过度遮住士兵。
- [ ] 死亡表现和残留淡出能区分存活与阵亡士兵。
- [ ] 多场战斗同时发生时，切换观看对象不会冻结其他战斗。
- [ ] 同一地块的增援加入原有战斗；撤退后部队经运输回到相邻己方领土。
- [ ] 清掉守军后继续攻击地块耐久；没能攻下的地块在脱离攻击后回复。

## 6. AI、胜负与性能（完整试玩）

- [ ] 先玩 48 地块 1v1，AI 能扩张、建设、补给、增援并威胁总部。
- [ ] 再试 1v3，多方能独立作战，画面操作不会明显卡住。
- [ ] 攻占敌总部会淘汰该军团，清掉全部对手后胜利；己方总部失守则失败。
- [ ] 胜负提示和返回主界面工作正常，新局没有残留旧战斗或局内蓝图。
- [ ] 训练场 120 对 120、160 对 160 能观看，后者的待增援人数逐步下降。
- [ ] 按 F3 查看帧率、实体数与模拟积压：在近景和频繁缩放时是否持续卡顿？
- [ ] 切到其他浏览器标签再回来，模拟能追赶经过的时间；注意积压是否长期不消退。
- [ ] 实际一局是否接近 20–30 分钟？是否存在黄金太多、生产太慢、优势滚雪球或长期僵持？
