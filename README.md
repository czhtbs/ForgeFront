# ForgeFront · 铸造前线

桌面浏览器单机即时战略游戏。Phaser 4 + TypeScript + Vite，无后端。地图采用 明亮浅色浮雕风格、固定平均尺度的随机分割地块；使用重绘建筑、单体地形装饰、模块化像素军队图标及俯视持枪士兵。

## 启动

先安装 Node.js（包含 npm；本项目已在 Node.js 24.16.0 验证）。Clone 仓库后，在仓库所在的上级目录打开终端，执行：

```powershell
cd ForgeFront
npm ci
npm run dev -- --host 127.0.0.1 --port 5180
```

浏览器打开 http://127.0.0.1:5180/ 即可游戏。首次需要安装依赖，以后在项目目录只需运行最后一条命令。运行时保持终端开启，按 `Ctrl+C` 关闭服务；不要直接双击 `index.html`。无需后端或数据库。

```powershell
npm test
npm run build
npm run probe
```

`test` 检查规则与确定性；`build` 执行类型检查和生产构建；`probe` 检查 240 实体与 48 地块四方 AI，结果不代表浏览器帧率。生产构建可用 `npm run preview -- --host 127.0.0.1 --port 5181` 预览。

## 第一次试玩

1. 菜单进入对局，选择小地图（40 地块）、1 名 AI；中／大地图分别为 60／80 地块，地块和单位尺度相同。
2. 每方开局有 40 名已装备步枪的军队、总部兵营和相邻金矿。左键从总部地块或军队图标拖到中立地块，松开派兵。
3. 部队可沿己方或中立地区前进，不能穿过敌占中间地区；跨入敌方或中立目标地块后，从入口逐个展开战斗模型。途经中立地块不自动占领；目标堡垒血量归零后才占领目标。
4. 在新占领地区建设工坊，选择机枪产出。从地图上的工坊建筑拖到己方兵营，建立补给线。
5. 兵营持续生成肉人，直到本地人数达到 60。未装备肉人不战斗、不能调动；供给抵达后逐人装配。
6. 已装备但未离营的士兵可以继续追加兼容装备；第一次派出后装备永久固定，返回兵营也不再装配。
7. 摧毁敌方总部取得胜利，查看战报并返回菜单。

## 生产与供给

- 黄金只用于建设、升级建筑，生成肉人和装配不花黄金。
- 一个兵营可以同时存在不同完成程度的配置。各装备按实际抵达的速率独立装配，优先补齐已有装备较多的士兵；原装备不会被重复消耗或整套覆盖。
- 输入必须整组兼容：多个不同主武器、毒气与火焰／爆炸、穿透与分裂均不能同时接入。建立冲突连线或切换出冲突的工坊产出会被直接拒绝，原线路和产出保持不变。
- 例如火箭筒、毒气、穿透供给依次变慢时，会同时出现火箭筒、火箭筒＋毒气、火箭筒＋毒气＋穿透。晚接入的兼容效果继续加到未离营士兵身上，已有武器不会浪费。
- 无装备连线或只有效果模块时，肉人不能出发、不自动获得步枪；可先装效果，再等待兼容主武器。
- 无装备库存。各项供给只累积正在装配的不足一件进度；没有可装配人员时该项供给浪费，不积攒供给供未来爆发式生产。主武器已装配后不替换，兼容效果只追加。
- 工坊的所有已建立连接等分总产能；不需要或被切断线路的份额不转给其他线路。删除连接后才重新均分。工坊或兵营失守时，其端点连接自动销毁并重新均分；仅途经地块失守仍按原通路重算规则处理。
- 满员只停止生成肉人，已有肉人仍能装配。额外援军和战斗幸存者不会被上限删除。
- 未装备肉人只在选中兵营／总部后的右栏显示人数，地图不显示其图标；顶部和战报只统计已装备兵力。驻营且可补装的士兵有金色状态点，右栏分别列出各配置人数。

## 地图操作

| 操作 | 效果 |
| --- | --- |
| 左键地块或建筑 | 单击只选择，不显示箭头；右栏覆盖地图，不移动镜头 |
| 从地块左键拖到另一地块 | 派出当地全部已装备人员，无须提前选中 |
| 点击军队图标，再拖动该图标 | 单击选择，长按约 280 毫秒或拖动超过 6 像素才显示军令 |
| Ctrl 点击军队图标 | 添加到选择，再点同一组取消；拖动任一已选图标统一下令 |
| 拖动行军中的装备图标 | 从当前位置改道，选择会随士兵保留，不需要等待抵达 |
| 交战中的己方组拖到相邻己方地块 | 撤退该组 |
| 从工坊建筑拖到己方兵营 | 建立装备线 |
| 选中工坊或兵营 | 关联线路加粗、共线路段分开以便选中 |
| 拖动高亮线段 | 插入路径点；松回原线上不新增 |
| 拖动路径点 | 移动该点，保留其他点 |
| 选中点后 Delete / “删除路径点” | 删除此点 |
| 选中线路后地图上方操作 | 删除连线或恢复最短路 |
| 右键拖动 | 平移地图，不发军令 |
| 滚轮 | 以鼠标位置为中心缩放 |
| H / 全图 | 返回全图 |
| Esc | 取消拖动与选择 |
| F3 | 查看运行状态 |

默认视图显示已装备军队图标、人数和交战提示。步兵在屏幕上的主体达到 6 像素时开始渐显，到 10 像素时完整显示，死亡碎片和战斗特效使用同一缩放过渡；视图不会改变战斗模拟。非战斗驻军和行军部队仍使用图标。跨入敌方或中立目标地块后，各阵营每 0.2 秒投入一名士兵；已经能攻击时不再强制向前挤出入口，否则继续接敌。未入场人员不会射击。同目标友军横向分散，无目标时不会主动挤向地块中心。占领完成后收起模型，若仍有残敌则保留军队和交战数据。

地块采用不规则 Voronoi 随机分割，平均面积固定约 9353 平方地图单位；40／60／80 地块只改变地图范围，不会将更多地块挤入固定画布。人物主体为 2.7 地图单位，战斗间距目标为 3.24，建筑为 22–36；步枪、机枪、火箭筒、狙击枪的射程分别为 32.4、38.88、48.6、58.32 地图单位，喷火器为 16.2。士兵在约九成射程处停止主动接近。行军与战场移动仍为 12 地图单位/秒，压制会减速。双方同时进入中立地块时优先互相接战；敌方还有待入场人员时，不绕过他们主动攻击堡垒。堡垒仍可能受到爆炸附带伤害。溅射／毒气半径为 3.6 地图单位，继续覆盖相邻士兵；伤害值未改。攻击建筑时，从贴图不透明区域选取不同落点，子弹实际飞向该位置。

阵亡时短促喷溅血点，头盔、武器和躯干部件击飞、落地；残留最多 5 秒后清理，战斗结束不会令这些效果突然消失。

选中地块以白色边缘每秒缓慢闪烁；占领时归属底色渐变并短暂提示。地表有连续的浅色草地、沙土、颗粒和地势明暗。树木和山峰为少量单体贴图：普通地块 0–1 个，山地最多 2 个，森林最多 5–7 棵；整张贴图不会跨出所属地块。建筑不再带阵营色椭圆底座。地图没有自动铺满的邻接道路，只显示已建立的补给线和选中行军路线。补给线从工坊建筑逐段展开到兵营建筑。选中工坊后，重合线路平行展开并标号；侧栏“补给线路”可逐条选择，只有所选线路显示可拖动路径点。每条线只有一个白色运输点沿整条路径连续移动。

地图不再显示地名。地图图标按已装备配置分组，未装备肉人不计入图标；右侧的“件/秒”是供给和装配速率，不是人数。行军图标单独显示在途人数。军令箭头带有弧度、厚度、高光和地面投影；进攻为红色，友方移动为黄色。工坊拖线进入兼容的己方兵营／总部地块后吸附到建筑中心。

## 装备试验场

从菜单进入约 10 地块的试验场。己方空地可免费建设工坊与兵营，工坊可选全部装备，使用与正式对局相同的连线规则。选中己方兵营后可测试当前配置，支持 40、120、160 对等规模；试验直接生成所选配置，与正式战斗使用同一套模拟。

没有蓝图编辑器、默认搭配、装备库存、账号、云存储或本地存档。刷新页面开始新会话。
