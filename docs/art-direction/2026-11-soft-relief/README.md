# 明亮地形与反馈修正

后续更新：正式游戏已采用半尺寸步兵、缩放渐显和逐件补装。当前规则以项目 `README.md` 为准，以下旧轮次的尺寸与验证数量仅作历史记录。

- 地块和建筑保持原尺寸；步兵主体从 5.4 缩到 2.7，间距 3.24，溅射／毒气半径 3.6。死亡部件同步缩小。
- 默认视图只显示已装备军队、人数和交战提示。步兵主体在屏幕达到 6–10 像素时渐显，特效同步过渡。
- 射程重新校准，步枪 32.4、狙击枪 58.32；能攻击时不再强制向前走出入口，同目标队伍横向分散，无目标时不向中心推进。
- 未装备肉人数量只在兵营／总部右栏显示；顶部与战报按已装备人数统计。
- 装备按每项抵达速率分别装配，优先补齐装备较多的驻营士兵。合计上限仍为 60，满员后继续补装；没有可用人员的供给浪费，不形成库存。首次离营后固定配置。
- 互斥连线和造成冲突的工坊产出切换直接拒绝。当前装备种类最多支持主武器加两个兼容效果，机制不限定装配步骤数。
- 本轮只做装配、兼容、离营固定、显示和射程的相关检查；复用正式绘图生成 `combat-overview.png` 与 `combat-death.png` 检查远近比例，没有使用浏览器自动操作或长局平衡测试。

本轮直接用于正式游戏。参考 `docs/art-direction/b-soft-relief.png` 的明亮草地、沙土与柔和地势明暗，由程序构建地图和地表纹理，没有生成整张地图图片替代游戏。

| 用户反馈 | 本轮实现 |
| --- | --- |
| 建筑下方蓝色阴影 | 删除阵营色椭圆，不再生成额外底座 |
| 地块应为随机分割 | 恢复 Voronoi 随机分割；40／60／80 块的平均面积均为 9353，单位尺寸固定 |
| 装饰太密 | 普通地块 0–1 个、山地最多 2 个、森林最多 5–7 棵；完整贴图仍限制在所属地块内 |
| 阵亡仅淡出 | 短促血点、地面血迹，现有躯干、头盔、武器及喷火罐部件散开、旋转、落地；最多保留 5 秒，战斗结束后仍继续显示 |
| 进攻队伍拥挤 | 战斗间距目标从 5.4 增至 6.48（20%），入口横向间距增加；移动之后对称推开重叠单位 |
| 地面缺乏细节 | 连续高度场产生柔和光照，叠加草地／沙土色差、细颗粒、少量浅纹理和沿海浅滩 |
| 建筑命中集中一点 | 从实际贴图 alpha 中提取命中采样点；子弹飞向这些点，并在那里产生碎屑，而非只随机移动命中特效 |
| 重合产线难选 | 关联线路平行分开、独立配色和编号；侧栏逐条选择，只显示所选线路的路径点 |
| 军令箭头单薄 | 弧形带状箭头、侧面厚度、边缘高光与地面投影；敌方／中立／被敌军争夺的目标用红色，正常友方移动用黄色 |
| 运输点跨地块重复 | 每条线路一个运输点，累计行进距离后映射到整条折线；经过拐点不新建点，速度状态改变时也不重置位置 |
| 整体色调偏暗 | 改为浅色面板、深色文字、明亮蓝水面和草地／沙土底色 |

为了保留范围武器对邻近士兵的作用，溅射与毒气半径调到 7.2 地图单位，略大于 6.48 的间距；伤害值未改。地图地势和装饰仍只影响画面，不增加移动阻挡或掩体规则。

`scripts/build-art.mjs` 复用现有 SVG 士兵部件生成 `public/assets/b-style/soldier-debris.png`，并从建筑贴图生成 `src/content/building-hits.ts`。无需新增运行依赖。

验证包含地图连通性与平均尺度、完整装饰边界、产线分离与精确选择、运输点跨段连续性、军令箭头形状／进攻判断、死亡事件保留与碎片生命周期、战斗间距、随机建筑命中及原有规则回归。

`scripts/capture-map.mjs` 复用正式 `MapScene` 的绘图调用生成本目录图片，用于检查全图、近景、产线、箭头和死亡部件。它们是离线绘制结果，不是浏览器截图。用户可在正式游戏中检查实际拖拽、动画和帧率。

本轮验证结果：62 项测试通过，生产构建通过，游戏入口与新资源均返回 HTTP 200。未使用浏览器自动操作，未进行长局平衡测试。
