# 部队装备与战斗效果升级设计

更新日期：2026-11-11。V1 已完成本地实现；历史讨论中的待定项以本文第 10 节落地决定与数值文档为准。

状态：V1 已在本地实现，尚未发布。本文保留装备、触发、工厂与表现的讨论过程；第 10 节记录实施时采用的具体决定，数值稿是当前初值，后续平衡仍由试玩检验。

后续已确认远程初始血量 200、近战 400、基础攻击均为 50、默认无甲，采用固定护甲减伤；冰霜无伤害、电弧无视护甲。留痕至少提供四次额外机会，三件武器配件＋一种附加效果的攻击间隔不超过 1.5 秒。完整候选数值、火焰与防护科技对抗及测算见[战斗与科技数值设计 V1](战斗与科技数值设计V1.md)。候选值与用户已确认约束在该文中分别标明。

本次升级以“基础命中伤害＋单一类型附加效果”为核心。每颗子弹默认有一次主效果触发机会，留痕可以额外触发，分裂子弹拥有独立的新机会。穿透、分裂、留痕等过程不削减伤害；效果伤害不会引发新的配件连锁。

当前已实现的旧规则见 [EQUIPMENT-ROADMAP.md](EQUIPMENT-ROADMAP.md)。本次升级按本文替换其中明确改变的部分；其他生产、出征、占领与联机规则继续沿用。本文不表示线上版本已经改变。

## 1 本次升级范围

- 部队右侧面板：属性图标、正视图小人、四个装备框、武器配件栏和一个战术芯片位。
- 将原配件工坊的职责细分为附加效果、武器配件、战术芯片和防具生产。
- 四种附加效果互斥；兵营同时接入多种不同类型时停工，断开冲突线路后恢复。
- 统一附加效果触发，取消飞行中的被动电弧，以及穿透、分裂等带来的伤害衰减或均分。
- 实现远距、近射、分火三个战术芯片，只作用于同一地块的战斗。
- 实现燃烧、冰冻和电弧作用于士兵本身的不同特效。
- 设计血量、攻击、近远程防护、攻速和移速的数值关系；具体数值及防具规则另行确认。

科技攻防博弈已纳入本轮设计：新增研究室，每座同时研发一项，同阵营多个研究室可并行不同项目；界面分附加效果强化、装备解锁、通用强化三个选项卡。名称、前置、费用、时间和初始解锁状态见[研究室与科技树设计](研究室与科技树设计.md)。通用强化采用生命、攻速、移速；此前四条五级科技草案不再采用。

科技强化在研发完成后立即作用于现有及未来所有部队，不受装备时间和出征状态限制，不需要重新装配。每项研发的费用与时间均固定，与部队人数无关。

## 2 装备分类与右侧面板

### 2.1 装备分类

| 类别 | 每名士兵的限制 | 内容 |
| --- | --- | --- |
| 武器 | 一种 | 当前步枪或剑 |
| 附加效果 | 零或一种类型 | 炸药、电弧、燃烧、冰冻 |
| 武器配件 | 可装多个，不重复装同一种 | 穿透、弹跳、分裂、返航、追踪、滞留、留痕、延时、抛射 |
| 战术芯片 | 最多一个 | 远距、近射、分火，三者互斥 |
| 远程防具 | 一个独立装备位 | 具体产品和属性待定 |
| 近战防具 | 一个独立装备位 | 具体产品和属性待定 |

本次不采用头盔＋胸甲槽位，也不再采用多种附加效果叠加的方案。远距或近射不能再同时叠加分火芯片。

武器本身提供普通攻击能力；没有附加效果时，子弹仍有正常的基础远程伤害。附加效果不是维持开火所必需的消耗弹药，不新增逐发弹药库存和补弹机制。

### 2.2 面板布局

面板从上到下排列：

1. 属性区：Q 版图标＋属性名称＋数值，显示血量、基础攻击力、远程防护／近战防护、攻击频率、移动速度。
2. 装备区：左侧为 SVG 风格的 2D 正视图小人；右侧为远程防具、近战防具、武器、附加效果四个框。原先讨论的“弹药框”随概念调整为附加效果框。
3. 武器配件栏：按已装备的配件逐个显示像素风图标和名称，容纳多个配件。
4. 战术芯片栏：一个芯片框，显示图标和名称。

小人持有的枪械或剑、穿戴的防具随装备改变。附加效果、穿透、分裂等武器配件以及芯片不改变小人的基础装备造型。士兵受火、冰、电作用时的临时特效另见第 7 节。

图标与现有素材保持一致，使用 SVG 实现清晰的像素风形状；装备不能只有图标而没有名称。面板保留简洁数据与短名称，不加入教程段落。建造和工厂产出继续使用两列图卡。

混合选中多种装备的部队时，如何选择展示对象、汇总人数以及显示不同血量，列为面板实施前的待定项，不能用一个代表小人的属性冒充整个选区。

## 3 工厂拆分与生产输入

兵营、发射器工坊和金矿继续保留。原配件工坊的职责细分为以下四类，数量为四类：

| 工厂 | 生产内容 |
| --- | --- |
| 弹药工厂 | 炸药、电弧、燃烧、冰冻四种附加效果；“弹药工厂”为目前提出的建筑名称，实际产出是附加效果装备 |
| 配件工厂 | 九种武器配件 |
| 战术芯片工厂 | 远距、近射、分火三种芯片 |
| 护甲工厂 | 远程防具与近战防具，具体款式待定 |

发射器工坊继续生产步枪和剑。新工厂的费用、产能、升级收益在数值阶段确定，不自动照搬旧工坊数值作为新版本定案。

另外新增研究室，用于效果强化、装备解锁与通用强化，不生产装备。它不是由配件工坊拆分出的第五类工厂。

沿用通过生产线在兵营装配、出征前可补装、首次武装出征后装备固定的基本规则。新增类别需要进入相同的连线、兼容检查与兵营中转流程，不能只在界面中改名。

### 3.1 单一附加效果与冲突停工

- 同一士兵／武器只能装一种附加效果类型。
- 兵营的有效供给配置包含两种或以上不同附加效果类型时，兵营停止工作。
- 按不同类型判断冲突；多条线路供应同一种效果不等于多种效果，产能仍按已有运输规则计算。
- 冲突不能靠选取第一条线路、轮流装不同效果或给士兵叠加效果解决。
- 玩家断开冲突供给线路，使有效配置恢复为零或一种类型后，解除冲突。
- 连线造成冲突时，必须体现停工结果；不能沿用“只拒绝第二条线，兵营继续工作”来代替本次规则。
- 连续中转的兵营需要按完整上游供给配置判断，避免只检查直接连接的工厂而漏掉冲突。
- 冲突停工不是清空已有士兵或装备的指令，不销毁既有部队和在途实体。

“停止工作”是否同时暂停招募、装配、人员中转和装备转发，以及总部兵营、工厂改产解除冲突的具体处理，尚需明确，见第 8 节。

## 4 基础伤害与附加效果触发

### 4.1 两种伤害来源

**基础命中伤害**由子弹直接命中造成。穿透后击中后续敌人仍造成正常完整伤害。

**附加效果伤害**由炸药、电弧或持续区域等效果造成。它可以伤害多个敌人，也可以附带已经定义的减速、冻结等状态，但不能再触发武器配件或另一轮附加效果。

“效果伤害只造成伤害”在这里的准确含义是“不引发新的配件连锁”，不表示删除燃烧持续伤害、冰霜控制或受击特效。

同一武器的子弹在穿透、弹跳、分裂等过程中不进行伤害衰减或均分。附加效果也不因留痕、分裂等触发来源而自动弱化。不同武器和效果本身的伤害值，以及防具减伤，仍由后续数值规则决定。

### 4.2 默认一次主触发

1. 每颗子弹生成时拥有一次尚未使用的主触发机会。
2. 第一次有效命中敌人时，造成基础命中伤害，并使用这次机会释放所装备的附加效果。
3. 如果到最大射程时仍未使用主触发机会，则在终点释放效果。
4. 已经释放后，后续命中和到达最大射程都不重复释放主效果。
5. 释放效果不自动等于销毁子弹；子弹仍可以按配件继续穿透、弹跳、返航或滞留。
6. 没有相应延续行为时，子弹按正常碰撞／寿命规则结束。

每次碰撞必须识别是否是一次新的有效接触，不能因为子弹连续数帧与同一个敌人重叠，就重复结算完整命中伤害。返航是否允许再次命中同一敌人，需要按往返碰撞规则明确，不能靠重置效果机会实现。

### 4.3 四种触发结果

| 附加效果 | 触发后发生什么 |
| --- | --- |
| 炸药 | 以触发位置为中心产生小范围爆炸 |
| 电弧 | 以触发位置为中心，电击半径范围内的多个敌人 |
| 燃烧 | 在触发位置生成燃烧区域，区域内士兵持续受影响 |
| 冰冻 | 在触发位置生成冰冻区域，区域内士兵积累寒冷后冻结，不造成伤害 |

电弧取消普通飞行过程中的自动周期放电，改为命中或达到最大射程时触发。电弧配合留痕时，才会因留痕触发而沿途放电。

触发器统一接收效果类型、触发位置、伤害来源等必要数据。弹体运动、碰撞、分裂生成与效果结算分开处理。爆炸命中、电击命中和区域伤害不会再次调用弹体碰撞的配件逻辑。

## 5 武器配件如何改变触发

| 配件 | 本次设计 |
| --- | --- |
| 穿透 | 后续有效命中仍造成完整基础伤害；不恢复已消耗的主效果机会 |
| 弹跳 | 改变弹体方向并继续攻击；不因弹跳自动恢复主效果机会或降低伤害 |
| 分裂 | 生成新的完整子弹；每枚新子弹有自己的基础伤害和一次新的主效果机会，继承父弹全部武器配件但移除分裂 |
| 返航 | 改变运动过程，继续遵守本颗子弹的主效果使用状态，不因开始回程自动恢复机会 |
| 追踪 | 改变弹体飞行方向，不自行增加效果触发次数 |
| 滞留 | 控制弹体停留与存续；是否额外授予周期触发、以及如何与其他配件组合，待定 |
| 留痕 | 沿飞行路径多次释放所装备的附加效果；这是主触发机会之外的额外触发，不消耗或重置主机会，不自动降低伤害 |
| 延时 | 延后效果实际释放；预约时即占用对应机会，不能在等待期间重复预约同一次效果 |
| 抛射 | 控制空中飞行和落地碰撞；沿用跨地块攻击的基本限制，触发器与留痕在抛射阶段的具体交互待定 |

### 5.1 分裂继承边界

- 子弹继承基础攻击数据、唯一的附加效果类型，以及除分裂外的全部武器配件。
- 子弹不按数量平分基础伤害或附加效果伤害，也不从父弹借用主触发机会。
- 父弹已经触发过效果，不妨碍新生成的子弹拥有新机会；生成子弹也不恢复父弹已消耗的机会。
- 子弹必须初始化自己的寿命、命中记录、触发状态、运动阶段和配件计时器，不能直接复制父弹已经耗尽或已经进入回程的运行状态。
- 父弹自身只能执行一次分裂；子弹没有分裂配件，不能再次分裂。
- 分裂发生在发射、命中还是终点，生成数量、方向，以及父弹分裂后是否继续存在，尚未确定。

例如“穿透＋炸药”的父弹第一次命中释放炸药，后续穿透继续造成完整直击伤害；如果它还触发分裂，新生成的每枚子弹仍各自拥有一次炸药效果机会，并继续带有穿透。

### 5.2 留痕与持续区域

留痕按路径多次调用同一种附加效果。炸药留痕产生沿途爆炸，电弧留痕产生沿途电击，燃烧和冰冻留痕分别留下对应区域。

留痕已要求至少四次额外机会。V1 候选方案为每颗子弹四次，按初始航程的 20%／40%／60%／80% 分布，去回程共用，分裂子弹各自计算。持续区域的持续时间与重叠结算见数值稿。实现不能沿用旧版“固定伤害 10% 的痕迹”或把所有效果都强制转换为同一种持续伤害区域。

同一次射击分裂出的子弹继承留痕，因此也可产生痕迹；痕迹造成的伤害不能继续分裂或生成更多痕迹。持续区域重叠是否叠加伤害属于待定数值规则，不默认套用此前提出的刷新／合并建议。

## 6 同地块战术芯片

| 芯片 | 作战行为 |
| --- | --- |
| 远距 | 尽量在最大有效射程附近攻击，敌近则后退、敌远则接近；移动限制在当前交战地块内 |
| 近射 | 主动靠近敌人，在较近距离持续射击，不突破武器的合法最小射程 |
| 分火 | 在本队可攻击目标之间分配火力，减少所有士兵同时瞄准同一敌人；敌人少时允许多人攻击同一目标 |

每名士兵最多一个芯片，不能将远距与分火等组合装配。未装备芯片时保留普通自动索敌和攻击行为。

芯片不自动跨地块追击、巡逻或撤退。距离区间、换目标条件、同队判定和近战／抛射兼容性留待实现前确定，避免来回抖动和每帧集体换目标。

## 7 士兵燃烧 冰冻与电弧特效

本次必须表现效果作用在战场士兵身上的状态，不能只有地面区域、弹体或爆炸动画。

| 状态 | 进入／受到作用时 | 持续表现 | 离开／结束时 |
| --- | --- | --- | --- |
| 燃烧 | 士兵身上出现火焰 | 身体逐渐被烧黑，仍可辨认阵营、装备和动作 | 脱离燃烧区域后恢复正常外观，不留下永久焦黑 |
| 冰冻 | 出现霜迹与局部冰晶 | 士兵渐渐被冰块覆盖，体现受冰冻作用的过程 | 脱离冰冻区域后冰块消失，恢复正常外观 |
| 电弧 | 电击直接落在士兵身上 | 短时电流、身体闪光或轮廓闪烁，能够与普通命中区分 | 电击特效短时结束，不能因一次电击永久保持带电 |

火焰、冰层和电流属于临时覆盖效果，不更换士兵的基础装备美术。电弧的具体形态和持续时间可通过动画样例评审。

离开一个区域但仍处于另一个同类型区域内，不应错误清除状态表现。多个不同状态同时存在时，需要保持士兵轮廓和阵营辨识，具体叠放优先级另定。

“离开区域恢复外观”是已确认的表现规则。实际减速、冻结是否同步解除、是否有残留时长，需要在数值阶段单独确认，不能由动画消失擅自决定伤害或控制状态。

纯视觉变化不消耗模拟随机数，不改变目标、伤害和移动。死亡、快照恢复、切换对局后不得留下错误的燃烧、焦黑、冰层或电流状态。特效评审提供可播放动画。

## 8 下一轮数值与防具讨论

### 8.1 已确认的数值边界

新版本远程初始血量为 200、近战为 400，基础攻击均为 50，默认没有护甲。护甲直接从对应伤害中扣减。炸药造成瞬间范围伤害，火焰造成小额高频持续伤害，冰霜只积累寒冷并冻结，电弧无视护甲直接扣血。允许低级火焰被护甲抵消，通过科技升级形成攻防博弈。

旧版 100 血量、步枪 16 伤害、剑 28 伤害已替换为上述新数值。其他候选数值、公式与验证范围见[战斗与科技数值设计 V1](战斗与科技数值设计V1.md)。

### 8.2 属性与成长

| 待讨论项 | 需要决定的内容 |
| --- | --- |
| 血量 | 基础值、装备是否改变上限、治疗是否属于后续范围 |
| 基础攻击力 | 武器基础伤害；附加效果伤害单列，避免用一个总攻击力掩盖范围伤害和持续伤害 |
| 附加效果 | 各自伤害、作用半径、电弧目标数量、区域持续时间、伤害频率及冰霜控制规则 |
| 攻击频率 | 采用每秒攻击次数还是攻击间隔作为主要展示，内部计算和显示保持一致 |
| 移动速度 | 基础速度、防具负担、近射与远距是否有移动代价 |
| 射程 | 是否增加射程属性展示，帮助理解远距和近射芯片 |
| 科技树／属性配件 | 科技分为效果强化、装备解锁和生命／攻速／移速强化，具体值见研究室设计；额外属性配件尚未确定 |

攻击力显示的建议是“基础攻击力＋附加效果独立数值”，还需确认具体展示方式；不把爆炸对多人造成的伤害加总成固定的面板攻击力。

### 8.3 防具

已经确定两个独立槽位为远程防具和近战防具，以及固定护甲减伤算法。轻型初始解锁，中型、重型需要逐级研发解锁；候选护甲值为 10／20／30，不再采用独立防护数值科技加成。生产时间、重量和效果见候选数值稿，尚待试玩验证。

下一轮优先讨论：

1. 固定护甲档位、解锁节奏与对不同阶段效果的免伤阈值。
2. 基础远程命中、近战命中、爆炸、电弧、燃烧与冰冻伤害分别受到哪种防护影响。
3. 防具是否影响移动速度或攻击频率，以及两件防具同时装备的代价。
4. 防具是否只有护甲值，还是还有耐久；不能默认额外引入耐久系统。
5. 护甲工厂的产品、产能、费用和升级收益。

### 8.4 尚待明确的行为边界

- 冲突停工暂停哪些环节；是否允许通过工厂改产而非断线解除；已装备旧效果的新兵在改线后如何处理。
- 剑是否使用附加效果、如何触发，以及哪些武器配件和芯片兼容近战。
- 分裂的时机、数量、初始轨迹、父弹存续，以及子弹抛射／返航的初始化方式。
- 穿透和弹跳次数、返航再次命中规则、滞留是否提供额外触发、延时与留痕是否共同延后。
- 留痕频率与次数、抛射空中是否留痕、区域重叠伤害与控制叠加。
- 兵营多芯片输入、防具同槽多种输入等冲突处理；不能直接套用为所有冲突都停工。
- 部队面板的混合选区展示，以及装备图标和防具造型。

上述待定项不改变本次已经确认的单一附加效果、完整伤害、一次主触发、留痕额外触发和禁止效果连锁规则。

实现后的基本验收包括：

- 普通命中、未命中到达射程终点、同帧碰撞与寿命结束，均只消耗一次主机会。
- 穿透后续直击不衰减，已经使用的附加效果不重复；无附加效果的子弹仍可正常攻击。
- 分裂子弹伤害完整、主机会独立、继承除分裂外的配件；不存在递归分裂或父弹重复分裂。
- 留痕可额外触发多次，不消耗主机会，不自动弱化效果；效果伤害不会产生更多子弹或配件连锁。
- 普通电弧弹飞行中不自动放电，主触发时可攻击多个敌人；电弧留痕按留痕规则放电。
- 多种附加效果输入使兵营停工，断开冲突线路后恢复；同类型多来源不误判，上游中转冲突不遗漏。
- 士兵最多一种附加效果和一个战术芯片；出征、撤退、驻留与恢复快照不丢装备。
- 火焰与焦黑、渐进冰层、电击状态可辨认；离开对应区域或电击结束后正确恢复。
- 士兵表现不改变模拟结果；相关多人命令、快照恢复与重放仍保持一致。

## 10 V1 落地决定（2026-11-11）

- 属性、四个独立装备框、正视图小人、多个武器配件和单个芯片已接入；混合选区按阵营与装备分组，每组显示人数和当前科技下的单兵生命上限。
- 装备默认显示名称与图标，数值放悬停／键盘聚焦信息。研究室默认显示图标、名称、阶级与状态，费用、时间、收益和前置也放悬停信息。
- 护甲采用数值稿的轻／中／重档位；剑只支持穿透，但可带一种附加效果，挥击首个命中统一触发。远距／近射仅支持普通步枪，分火支持剑和指定战场内的抛射。
- 多类型弹药输入时，总部与普通兵营都暂停招募、装配、人员中转和装备转发，保留已有人员、装备与在途运输。停工状态保持到断开相关供给线路且冲突已消失；单独改产不会解锁已发生的冲突。断线后仍有多种输入则继续停工。同类型多来源可正常使用。
- 同槽防具或多个芯片仍拒绝冲突连线，不延伸弹药停工规则。已装备旧效果的新兵不会自动换装；改线后新兵按可装备资格继续补装。
- 分裂在首次主触发时产生三枚完整子弹；每枚子弹继承除分裂外的配件，初始航程 12；父弹继续执行自身配件。
- 穿透／弹跳／返航直击预算相加，最多 6 次；滞留不额外发放主效果。延时统一为 0.8 秒，主效果和留痕均在预约位置延后生效。
- 留痕每颗子弹四次，往返共享次数；分裂子弹独立计数。抛射按投影位置留痕，到选定落点即视为航程终点。
- 火区重叠取最高实际跳伤，冰区取最高寒冷增长；不累加同类区域数量。离开区域清除对应状态，解冻保留一秒免疫。
- 科技完整 30 项，固定费用和时长，完成即强化现有与未来部队；已有弹体、预约效果与持续区域后续结算读取当前等级。
- 研究室地图素材使用内置生图工具，参考现有工坊和兵营；原图与压缩图保存在 `docs/art/research-lab/`。

验证与可播放状态特效：[装备升级验收](../verification/equipment-upgrade/README.md)。
