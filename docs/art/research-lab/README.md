# 研究室地图素材

2026-11-11，使用内置生图工具生成；风格参考 `public/assets/b-style/workshop.png` 与 `barracks.png`。

提示词：单座军用研究室，匹配参考建筑的等距斜视角、左上照明、卡其墙面、灰蓝屋顶与简约低多边形明暗。低矮主体配圆顶、青绿色窗带和侧门，轮廓在 32 像素下可辨。居中，完整建筑，透明底，无地块、场景、人物、文字或标志。参考图仅用于风格，不复制参考建筑。

`original.png` 保留生图原图；`map-sprite.png` 为裁去透明边距、缩小压缩后的地图用图，实际游戏读取 `public/assets/b-style/researchLab.png`。
